3. SETUP FOR DIFFERENT NETWORKS (Mobile Data)

   A. Find Your Public IP:
      ► Visit: https://whatismyipaddress.com/
      ► Write it down (e.g., 203.45.67.89)
   
   B. Setup Router Port Forwarding:
      ► Login to router: http://192.168.1.1
      ► Find "Port Forwarding" or "Virtual Server"
      ► Add new rule:
         - Service Name: Rover WebRTC
         - External Port: 9000
         - Internal IP: 192.168.1.12
         - Internal Port: 9000
         - Protocol: TCP
      ► Save and restart router
   
   C. Update Android App:
      Server URL: ws://YOUR_PUBLIC_IP:9000
      (e.g., ws://203.45.67.89:9000)
   
   D. Test:
      ► Turn OFF WiFi on Android (use mobile data)
      ► Tap "START STREAMING"
      ► Should connect in 1-2 seconds!

❓ TROUBLESHOOTING:

   ❌ Can't connect from Android:
      1. Check server is running (terminal window open)
      2. Check firewall (run setup-firewall.bat as admin)
      3. Check port forwarding (router settings)
      4. Use correct IP address
      5. Use ws:// not wss://
   
   ❌ Port already in use:
      1. Run: taskkill /F /IM node.exe
      2. Start server again
   
   ❌ Server crashed:
      1. Just run: node server.js again
