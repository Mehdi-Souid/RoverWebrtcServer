========================================
   SERVER MANAGEMENT
========================================

To STOP server:
   - Press Ctrl+C in the terminal window

To START server again:
   - Double-click: start-server.bat
   - Or run: node server.js

To check if server is running:
   - Visit: http://localhost:9000/health
   - Should show: {"status":"ok"}

========================================
   TROUBLESHOOTING
========================================

❌ Can't connect from Android (different network):
   1. Check firewall is open (run setup-firewall.bat)
   2. Check port forwarding is setup
   3. Use correct public IP
   4. Use ws:// not wss://

❌ Port 9000 already in use:
   - Run: taskkill /F /IM node.exe
   - Then start server again

❌ Server crashed:
   - Just run: node server.js again
   - Or double-click: start-server.bat

========================================
   AUTO-START ON BOOT (OPTIONAL)
========================================

To make server start automatically when Windows boots:

1. Press Win+R
2. Type: shell:startup
3. Create shortcut to: start-server.bat
4. Place shortcut in startup folder
